# Simon Says Game 🎮


## 📌 Task Description
This project is an implementation of **Task #2 – Simon Says** from the Rolling Scopes School Stage 1 program.

https://github.com/rolling-scopes-school/tasks/tree/master/stage1/tasks/simon-says

The task was to build a browser-based memory game inspired by the classic **Simon Says** mechanics, following the provided technical specification (TS).

The visual and interaction style is inspired by the TV series **_Squid Game_**, with a focus on tension, simplicity, and clear user feedback.

---

## 🧠 Game Overview
**Simon Says** is a memory game where the player must repeat an increasingly long sequence of signals.

Game flow:
1. The game shows a sequence of highlighted buttons.
2. The player repeats the sequence by clicking the buttons in the same order.
3. With each successful round, the sequence becomes longer.
4. A mistake ends the game and resets progress.
